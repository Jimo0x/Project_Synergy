Comment obtenir un devis pour mon projet ?

Pour obtenir un devis personnalisé :

  • Contactez-nous via WhatsApp, téléphone ou email
  • Décrivez votre projet en détail (objectifs, fonctionnalités, délais)
  • Notre équipe analysera vos besoins sous 24h
  • Vous recevrez un devis détaillé et transparent
Quels sont vos délais de livraison ?

Nos délais varient selon la complexité du projet :

  • Site vitrine : 10-15 jours ouvrables
  • E-commerce : 15-25 jours ouvrables
  • Application web : 1-3 mois
  • Design graphique : 3-7 jours
  • Des options express sont disponibles (+30%)
Comment fonctionne le support après livraison ?

Notre support post-livraison comprend :

  • 30 jours de garantie : Corrections gratuites
  • Support technique : 6 mois inclus (extensible)
  • Formation : Session complète d'utilisation
  • Maintenance : Forfaits mensuels disponibles
  • Assistance 24/7 : Pour les projets critiques
Quels modes de paiement acceptez-vous ?

Nous acceptons plusieurs modes de paiement :

  • Mobile Money (MTN, Moov)
  • Wave
  • Virements bancaires
  • Cartes Visa/Mastercard
  • PayPal pour les clients internationaux

Options de paiement échelonné disponibles.
